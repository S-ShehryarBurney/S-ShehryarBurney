## 📌 Featured Projects

### 🤖 AI Business Operations Assistant

An AI-powered business assistant designed to answer operational questions using a company's own business data and internal documents.

The system combines **LLM tool calling, PostgreSQL, SQLAlchemy, and Retrieval-Augmented Generation (RAG)** to provide grounded responses.

#### Key Features

- Built a tool-calling AI agent
- Implemented business data retrieval through structured tools
- Connected the agent to PostgreSQL through SQLAlchemy
- Built a RAG pipeline for company policy documents
- Implemented document chunking and embeddings
- Added semantic similarity search using `pgvector`
- Separated document ingestion from retrieval
- Implemented API-based backend components
- Integrated n8n as the workflow orchestration layer
- Designed the system to combine structured business data with unstructured company documents

#### Architecture

```text
User
  ↓
n8n
  ↓
AI Agent
  ↓
┌───────────────────────┐
│                       │
Business Tools          RAG
│                       │
↓                       ↓
PostgreSQL          pgvector
│                       │
└───────────┬───────────┘
            ↓
       Validation
            ↓
         Response
```

**Technologies:** `Python` `FastAPI` `OpenAI SDK` `OpenRouter` `PostgreSQL` `SQLAlchemy` `pgvector` `n8n`
